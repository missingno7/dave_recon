## Verification standard

- `tools/match_function.py` / `tools/match_asm.py`: compile/assemble, place,
  resolve EVERY fixup through `tools/symbols.py` (library map, curated names,
  `F_XXXX` / `D_XXXX` / `P<PARA>_<OFF>` placeholders), check base16 fixups
  against real MZ relocations, compare linked bytes and the module's `_DATA`.
  Nothing is masked.
- `tools/reconstruct.py` builds MATCHING_C/ASM regions from compiler/assembler
  output (`tools/verify_sources.py`) and STRUCTURED_DATA from codecs
  (`tools/structured.py`); only KNOWN_LIBRARY, headers and raw regions come
  from extracts.

## Toolchain (all pinned, `python tools/bootstrap.py`)

Turbo C++ 1.00 `tcc -c -ms -1- -f- -N -G` (docs/compiler-behaviors.md);
TASM 2.0 single pass `/mx` for the ASM modules and for TCC's inline-asm
restarts (layout/assembler.json); TLINK 3.0; C0S.OBJ + CS.LIB; LZEXE 0.91.

## Explicitly forbidden

Masking or loosening comparisons; inline asm or byte emission that the
original did not have; placeholder logic; hard-coding addresses into the final
build; silently switching oracle or toolchain versions.
